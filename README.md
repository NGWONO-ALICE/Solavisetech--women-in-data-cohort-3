# SolaviseTech Women in Data Cohort 3

## About the Program

The SolaviseTech Women in Data Cohort 3 program is a learning opportunity designed to help women develop practical data analysis skills and build confidence in working with data.

## My Goals

By the end of this program, I aim to:

* Develop data analysis skills using Excel, SQL, and Python.
* Learn how to clean, analyze, and interpret datasets.
* Create data visualizations and dashboards.
* Complete practical data analysis projects.
* Build a portfolio to showcase my skills to potential employers.
* Improve my problem-solving and analytical thinking skills.

## My Commitment

I am committed to learning consistently, practicing my skills, collaborating with other learners, and applying my knowledge to real-world problems.

My goal is to become a competent data analyst who can turn data into meaningful insights and support informed decision-making.
